# User Stories – BMI Tracker

> รูปแบบ: “ในฐานะผู้ใช้ ฉันต้องการ… เพื่อให้…”

1. ในฐานะผู้ใช้ ฉันต้องการกรอกน้ำหนักและส่วนสูง เพื่อให้ระบบช่วยคำนวณค่า BMI ให้โดยอัตโนมัติ  
2. ในฐานะผู้ใช้ ฉันต้องการให้ระบบตรวจสอบว่าค่าที่กรอกเป็นตัวเลขและอยู่ในช่วงปกติ เพื่อป้องกันการคำนวณผิดพลาด  
3. ในฐานะผู้ใช้ ฉันต้องการเห็นค่า BMI และหมวดหมู่สุขภาพของฉันทันทีหลังจากกดคำนวณ เพื่อให้เข้าใจสถานะสุขภาพของตัวเองตอนนี้  
4. ในฐานะผู้ใช้ ฉันต้องการให้ระบบบันทึกข้อมูลน้ำหนัก ส่วนสูง และ BMI ทุกครั้งที่คำนวณ เพื่อให้สามารถดูประวัติย้อนหลังได้  
5. ในฐานะผู้ใช้ ฉันต้องการดูข้อมูลประวัติในรูปแบบตาราง เพื่อให้เปรียบเทียบค่า BMI ในแต่ละวันได้ง่าย  
6. ในฐานะผู้ใช้ ฉันต้องการดูกราฟเส้นแสดงแนวโน้ม BMI ตามลำดับเวลา เพื่อให้เห็นว่าค่า BMI ของฉันเพิ่มขึ้นหรือลดลง  
7. ในฐานะผู้ใช้ ฉันต้องการลบรายการประวัติที่กรอกผิดออกจากระบบได้ เพื่อให้ข้อมูลที่เก็บไว้ถูกต้อง  
8. ในฐานะผู้ใช้ ฉันต้องการให้ระบบจำข้อมูลประวัติของฉันแม้ปิดเบราว์เซอร์ไปแล้ว เพื่อไม่ต้องกรอกใหม่ทุกครั้ง  
9. ในฐานะผู้ใช้ ฉันต้องการให้ระบบแสดงข้อความแจ้งเตือนเมื่อฉันไม่ได้กรอกข้อมูล หรือกรอกผิดรูปแบบ เพื่อรู้ว่าต้องแก้ตรงไหน  
10. ในฐานะผู้ใช้ ฉันต้องการ UI ที่เข้าใจง่าย ใช้งานได้บนคอมและมือถือ เพื่อให้สามารถใช้ระบบได้ทุกที่ทุกเวลา
