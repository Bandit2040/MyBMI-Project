📂 โครงสร้างโฟลเดอร์โครงการ (Project Structure) 

โครงการถูกจัดลำดับตามกระบวนการ SDLC ทั้ง 6 ขั้นตอน ดังนี้: 
01_Requirements: เก็บเอกสารขอบเขต (Scope Document) และ User Stories ทั้ง 10 ข้อ 
02_UX_UI_Design: เก็บภาพจำลองหน้าจอ (Prototype) และเหตุผลในการออกแบบ (Design Rationale) 
03_System_Design: แสดงแผนภาพสถาปัตยกรรม (Architecture) และการตัดสินใจเลือกใช้ Technology Stack 
04_Implementation: แหล่งเก็บ Source Code หลักของแอปพลิเคชัน (React/Node.js) 
05_Testing: รายงานการทดสอบ (Test Case Report) 10 กรณี และภาพหลักฐานการทดสอบ 
06_Deployment_Review: คู่มือการใช้งานระบบ (User Manual) และลิงก์วิดีโอนำเสนอ 

🚀 วิธีการติดตั้งและรันโปรแกรม (Installation & How to run) 
1. การเตรียมระบบ
ตรวจสอบว่าเครื่องของคุณติดตั้ง Node.js เรียบร้อยแล้ว
ดาวน์โหลดโปรเจกต์นี้จาก GitHub หรือใช้คำสั่ง git clone

3. วิธีการรัน
เปิด Terminal และเข้าไปยังโฟลเดอร์โปรเจกต์: cd MyBMI-Project/04_Implementation
ติดตั้ง Dependency: npm install
เริ่มการทำงานของแอปพลิเคชัน: npm run dev
เปิดเว็บเบราว์เซอร์ไปที่ลิงก์ที่ระบบแจ้ง (ปกติคือ http://localhost:5173)
